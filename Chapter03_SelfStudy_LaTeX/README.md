# 第三章完整自讀投影片

以 `textbook.pdf` 中 R. P. G. Collinson《Introduction to Avionics Systems》第 3 版第三章為來源，整理成繁體中文 LaTeX Beamer 投影片，共 177 頁。

## 開始閱讀

- `chapter03_slides.pdf`：直接閱讀的投影片，含書籤。
- `chapter03_slides.tex`：可修改的完整 LaTeX 原始檔，包含原有推導與圖表，並引用 `figures/` 的課本原圖；搬移時請保留該資料夾。
- `compile.ps1`：在本機使用 XeLaTeX 編譯兩次並更新 PDF。
- `figures/`：59 張課本原始分圖與來源資料。
- `FIGURE_INDEX.md`：原圖、教材頁碼與更新後投影片頁碼的對照。
- `build/`：編譯紀錄、版面預覽與計算核對資料，可忽略。

範圍為書上 pp. 101–177，對應原 PDF 檔案的第 116–192 頁。原教材檔案保持不變。

## 正負號與教材核對

機體軸採 x 向前、y 向右、z 向下。氣動導數預設帶符號。短週期推導另外定義正的恢復／阻尼大小值 a、b、c，避免與原書方塊圖的符號切換混用。阻尼比寫成 ζ_d，與方向舵角 ζ 分開。

已區分教材原值與依方程重算的值，包括 p. 147 的 A1 加法、後續阻尼比與 SAS 增益、p. 149 的轉彎率、滾轉與純偏航公式正負號，以及 p. 153 的模型階數。核對說明是依原書內部方程重新計算，不代表出版社正式勘誤表。

資料與典型機型敘述以 2011 年教材為背景。自編練習、延伸推導與示意響應均在投影片上標明，不冒充真機試驗資料。

## 編譯

使用已安裝的 XeLaTeX，需有 Beamer、ctex、pgfplots 套件及 Microsoft JhengHei（微軟正黑體）字型。

在本資料夾執行：

```powershell
.\compile.ps1
```

或在命令列直接執行兩次：

```text
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build chapter03_slides.tex
```

編譯腳本會將 `build/chapter03_slides.pdf` 複製到此資料夾根目錄。兩次編譯用來更新總頁數和書籤。

本次 Codex 內建編譯器回報 `Unable to find standard directories for platform`，所以以本機既有 XeLaTeX 產出並檢查 PDF。原始檔保留於內建編輯器，可繼續修改。加入原圖後需使用本機編譯，內建編譯器也不支援這類多檔圖片專案。已輸出的 PDF 不受此預覽環境問題影響。
